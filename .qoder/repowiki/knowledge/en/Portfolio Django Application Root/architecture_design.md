The root directory is the Django project entry point: `manage.py` bootstraps the project via `DJANGO_SETTINGS_MODULE=core.settings`, which wires the `portfolio_app` into URL routing. The public site is a client-rendered SPA — `index.html` + `main.js` + `style.css` are served as static assets and fetch all dynamic content from `/api/portfolio/`, while user submissions (contact form) POST to `/api/contact/`. The same Django backend also exposes the admin dashboard (`/admin-login/`) backed by the `templates_and_static` package, so editors manage profile, projects, skills, etc., and the public SPA consumes that data through the shared API layer.
